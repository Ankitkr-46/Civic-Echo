# CivicEcho: AI-Powered Public Complaint Platform

**CivicEcho** is a state-of-the-art, full-stack citizen engagement and municipal response platform. Designed with mobile-first accessibility and premium aesthetics in mind, it allows citizens to report municipal disruptions (via text, live voice dictation, and media attachments) and enables administrators to monitor, route, and resolve these issues efficiently via a central command dashboard.

---

## 🌟 Key Features

### 1. Citizen Portal
*   **Speech-to-Text AI Dictation**: Speak directly into the microphone. Built-in web speech dictation transcribes and injects voice input into description blocks in real-time.
*   **Interactive Geocoding Map**: Geolocation automatically requests coordinates and displays an OpenStreetMap Leaflet map. Drag the pin manually to resolve physical addresses dynamically using the Nominatim API.
*   **Live AI Preview**: Click "Test AI" before submitting to preview predicted category confidence, urgency priority, and short summaries generated by our AI pipeline.
*   **Community Feed**: Public feed allowing citizens to search, filter (by category, priority, and status), upvote issues ("I have this same issue"), and post comments.
*   **In-App Alerts**: Automated notifications informing citizens in real-time as admins dispatch, update, or resolve their reports.

### 2. Admin Command Dashboard
*   **Analytics Dashboard Overview**: Responsive statistics panels for total active tickets, unresolved queues, resolution rates, and SLA progress.
*   **Interactive Recharts Share**: Beautiful responsive charts mapping public disruptions distribution.
*   **Incident Heat Map**: Spatial Leaflet map displaying active complaints color-coded dynamically by priority (Red = High priority emergencies).
*   **Ledger Table**: Rich tabular dataset supporting keyword searches, sorting, and filters.
*   **Immersive Detail Drawer**: A sliding control drawer containing:
    *   Citizen profile metadata, physical addresses, images, and audio attachments.
    *   AI Co-Pilot advice routing details.
    *   Incident Dispatch Form: Dropdowns to update status (Submitted → Assigned → Resolved), assign field officers, adjust priorities, select departments, and log official responses.

## 🛠️ Technology Stack

*   **Frontend & API Backend**: [Next.js](https://nextjs.org/) (App Router, Unified Full-stack architecture, ES module TypeScript compliance).
*   **Styling & Icons**: [Tailwind CSS v4](https://tailwindcss.com/) (Navy-slate government theme tokens, premium scrollbars, micro-animations) & [Lucide React](https://lucide.dev/).
*   **Database, Real-time & Storage**: [Supabase](https://supabase.com/) (PostgreSQL cloud, pre-seeded schemas, triggers for auto-updating timestamps, and Row Level Security policies).
*   **Interactive Mapping**: [Leaflet.js](https://leafletjs.org/) with OpenStreetMap tiles.
*   **Analytics Charts**: [Recharts](https://recharts.org/).
*   **AI Engine**: [Gemini API](https://ai.google.dev/) (Dynamic processing pipeline with offline pattern matching fallbacks for resiliency).

## ⚙️ Installation & Setup

1.  **Clone the Repository**:
    ```bash
    git clone https://github.com/Ankitkr-46/Civic-Echo.git
    cd Civic-Echo
    ```

2.  **Install Dependencies**:
    ```bash
    npm install
    ```

3.  **Setup Environment Variables**:
    Create a `.env.local` file in the root directory:
    ```env
    NEXT_PUBLIC_SUPABASE_URL=https://fgbxdwdqstgwkaclnkse.supabase.co
    NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
    SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key
    # Optional: Swap this for a real Gemini API Key if you have one
    NEXT_PUBLIC_GEMINI_API_KEY=
    ```

4.  **Run Development Server**:
    ```bash
    npm run dev
    ```
    Open [http://localhost:3000](http://localhost:3000) in your web browser.

5.  **Compile Production Bundle**:
    ```bash
    npm run build
    ```
